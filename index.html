Install Firmware

1

Connect your T-Display to your computer using a USB-C data cable.

2

Click Connect & Flash below and choose your USB serial port in the pop-up.

3

Confirm Install to write the firmware in ~15 seconds.

Hardware Controls & Pinout

Input GPIO Pin Action
Button 1 (Left / Top) GPIO 0 Short press: Cycle color theme
Long press (>1.5s): Flip rotation 180°
Button 2 (Right / Bottom) GPIO 35 Short press: Switch screen (Greeting → SysInfo → Alphabet)
Backlight Control GPIO 4 ST7789 Backlight power (Active HIGH)
SPI Display Bus MOSI 19, SCLK 18, CS 5, DC 16, RST 23 ST7789 IPS 240x135 LCD

Manual Downloads & Offline Flashing

If you prefer flashing manually using esptool.py:

File Size Flashing Offset
merged-firmware.bin (All-in-One) ~390 KB 0x0 (Single command full flash)
firmware.bin (App only) ~325 KB 0x10000
bootloader.bin ~23 KB 0x1000
partitions.bin ~3 KB 0x8000
One-liner flash command: esptool.py --chip esp32 write_flash 0x0 merged-firmware.bin
